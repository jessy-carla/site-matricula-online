# 🎓 Site de Matrícula Online

## 📚 Projeto Acadêmico — SENAI

Projeto desenvolvido como atividade acadêmica do **SENAI**, com o objetivo de criar uma interface web para simular um processo de **matrícula online**.

A aplicação foi desenvolvida buscando proporcionar uma experiência simples, organizada e intuitiva para o preenchimento dos dados necessários para uma matrícula.

---

## 🎯 Objetivo

Desenvolver um site de matrícula que permita ao usuário preencher seus dados e realizar o cadastro de forma digital, aplicando conceitos de **desenvolvimento web, estruturação de páginas, formulários e responsividade**.

---

## 💻 Tecnologias Utilizadas

* HTML5
* CSS3
* JavaScript
* Bootstrap
* Git
* GitHub

---

## ⚙️ Funcionalidades

O projeto possui uma interface destinada ao processo de matrícula, incluindo:

* 📝 Formulário de matrícula;
* 👤 Cadastro de informações do aluno;
* 📚 Seleção de curso;
* 📅 Seleção de informações relacionadas à matrícula;
* ✅ Validação dos campos;
* 📱 Layout responsivo;
* 💻 Interface adaptada para diferentes tamanhos de tela.

## 🚀 Como executar o projeto

### 1. Clone o repositório

```bash
git clone https://github.com/jessy-carla/site-matricula-online.git
```

### 2. Acesse a pasta

```bash
cd site-matricula-online
```

### 3. Execute o projeto

Abra o arquivo:

```text
index.html
```

O projeto também pode ser executado utilizando a extensão **Live Server** no Visual Studio Code.
